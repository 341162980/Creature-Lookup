Creature Lookup is a Flask web app that serves as an interactive animal encyclopedia. 
It has pages which:
Search for any animal in the database to view its stats, habitat map, image, and other details.
Search an animal to see a visual diagram of its food chain.
Generate graphs and visuals from the dataset using customizable inputs.
Allow users to submit a new animal request or a data change request

HOW TO USE: 

1. Download all files as a zip by clicking the green "Code" button
2. Install Visual Studio Code
3. Install Python from python.org or via VS Code
4. Open terminal by pressing "Ctrl + `" or "Cmd + `"
5. Run the command: pip install -r requirements.txt
6. Then, run: "python app.py" or "python3 app.py"
7. Open http://127.0.0.1:5000 in your browser
8. To quit, type ctrl c in the terminal and the web server will close

Technologies Used

Python & Flask — backend routing, search, and data processing
Pandas — data loading, filtering, and preprocessing
Wikipedia API (Requests) — dynamic animal image fetching
GeoPandas & Natural Earth — habitat map generation
Matplotlib & NumPy — graph and heatmap generation
HTML, CSS, JavaScript — frontend design and interactivity
