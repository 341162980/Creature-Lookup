Install pandas: "pip install pandas" or "pip3 install pandas"

Install flask: "pip install flask"


For wikipedia images, user must run: "pip install wikipedia-api requests"
and "pip install requests"

For world map images, user must run: "pip install geopandas matplotlib"
and "pip install geodatasets"

    -dataset comes from Natural Earth (built into geopandas)


HOW TO USE: 

-open in vs code
-user needs python on environment first
run "pip install -r requirements.txt"

Type "python3 app.py" (must be ran for link to work)

Open your browser and go to: "http://127.0.0.1:5000"

- "ctrl c" to quit
