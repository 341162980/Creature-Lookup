About the Creator

Hi, I'm Kevin. I've had a passion for animals since I was little, and over time I developed a strong interest in working with data. This project was a combination of both so that I can build something around topics I that interest me.

The Database

Creature Lookup is built around a dataset of animals from across the world. The dataset was cleaned for this project but it still contains many flaws which is why others can provide feedback on how it can be improved. It currently covers hundreds of species and it has with room to grow, which is why anyone can suggest changes through the Contribute page.

Tools & Technologies

Creature Lookup is built with Python and Flask, which powers the backend routing, search, and data processing. The frontend is written in HTML, CSS, and JavaScript.

Wikipedia API — Animal images are found using the Wikipedia PageImages API. This provides the images during animal and food chain lookups.

GeoPandas & Natural Earth — The habitat maps are generated using GeoPandas with Natural Earth shapefiles. When you search for an animal, its territorial range is highlighted green on a world map. The maps often take some time to generate which explains the longer search times.

Matplotlib & NumPy — The Plots page allows users to generate bar charts, pie charts, scatter plots, and heatmaps from the dataset. These are produced using Matplotlib with NumPy.

Pandas — All data loading, searching, filtering, and preprocessing is handled using Pandas DataFrames throughout the application.
