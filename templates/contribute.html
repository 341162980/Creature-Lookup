Here, you can contribute to the site yourself! Don't see your favourite animal? See some info that's not entirely accurate?

Feel free to use this page and submit change requests to the dataset. Changes won't always be granted but upon review, you might just see your request make it onto the site.

Fill in your animal's data below. Follow a similar format as the example shown — keep commas between values, don't enter units, and for quantitative values, you can enter exact numbers or a range (e.g. "10-20").

For entries with multiple values, make sure to put them between quotatations (e.g. "Mexico, South America"). Leave a field as "Unknown" if you're unsure. You can add your input on the line below the Bengal Tiger example.

Once you click submit, it will open a new tab allowing you to send your new animal entry via gmail. Then, I can process this request and it will be added to the site database if it can pass all validation tests.
